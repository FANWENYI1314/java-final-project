## 1. 项目主题理由
贪吃蛇是一款经典且具有代表性的益智游戏。选择该项目作为 Java 期末项目的主要理由如下：
* **巩固面向对象思想**：项目通过将游戏窗体、核心画布、游戏元素（蛇身、食物）进行模块化设计，完美践行了封装、继承和多态的面向对象编程原则。
* **综合技术应用**：全面应用了 Java Swing 图形用户界面开发、`Timer` 定时器多线程机制、`KeyAdapter` 键盘事件监听以及碰撞检测算法。
* **实用性与可玩性兼备**：游戏具备流畅的交互体验、即时计分和失败结算机制，既满足了课程对程序复杂度的要求，又具备良好的视觉反馈。

## 2. 相关研究与技术栈
在本项目开发前，调研了传统的控制台贪吃蛇程序与基于 GUI 的桌面小游戏架构：
* **核心开发语言**：Java (JDK 8 或以上版本)
* **GUI 框架**：`javax.swing.*`（用于构建高性能的窗口、面板与自定义图形绘制）
* **事件处理**：`java.awt.event.*`（用于精准捕获键盘上下左右方向键，防止蛇反向移动自杀）
* **多线程与定时机制**：`javax.swing.Timer`（控制游戏画面的统一刷新帧率）

## 3. 项目设计
本系统主要由以下三大核心类和模块组成：
1. **`SnakeGame` 类（主入口）**：继承自 `JFrame`，负责初始化游戏窗口大小、标题、关闭属性，并加载游戏核心画布。
2. **`GamePanel` 类（核心画布与逻辑控制）**：继承自 `JPanel` 并实现 `ActionListener` 接口。
   * 负责维护蛇身体坐标数组 (`x[]`, `y[]`)、当前分数 (`score`) 以及运行状态 (`running`)。
   * 重写 `paintComponent` 方法，实现网格、红苹果食物、绿色蛇身以及实时分数的动态绘制。
3. **`MyKeyAdapter` 内部类（键盘监听）**：继承自 `KeyAdapter`，拦截玩家的按键动作并实时更新蛇的运动方向。

## 4. 实施过程与开发难点
* **环境搭建**：使用 Eclipse 集成开发环境创建 `JavaSnakeGame` 项目，规范包结构与源代码管理。
* **开发难点与突破**：
  * *难点一：蛇身跟随移动逻辑*。蛇在移动时，每一节身体需要依次向前一节的位置移动（`x[i] = x[i-1]`）。通过倒序循环遍历完美解决了身体跟随蛇头移动的问题。
  * *难点二：防止 180 度直接掉头*。在键盘监听中加入了方向校验逻辑（例如当前向右时，按左键无效），避免了非自然的自杀式碰撞。

* **项目完成度**：本程序成功实现了贪吃蛇的自动移动、吃到食物变长加分、墙壁碰撞检测、身体碰撞检测以及失败后的 “Game Over” 结算画面。
